# Love Web ♡

A cute little love website — dreamy pink aesthetics, floating hearts, sweet animations, and lovely surprises. 🎀

## Stack

- **React 18** + **TypeScript**
- **Vite 6** (build tool)
- **Tailwind CSS 3** (styling)
- **Lucide React** (icons)

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview the production build
npm run preview
```

> **Note:** On Windows systems where PowerShell execution policy blocks `.ps1` scripts, run the commands via Command Prompt (`cmd`) or use the scripts directly:
> ```
> node_modules\.bin\vite
> node_modules\.bin\vite build
> ```

## Sections

| Section | Description |
|---|---|
| **Home ♡** | Welcome screen with days-together counter |
| **Our Story** | Editable romantic timeline with moments |
| **Love Notes** | Digital love letters you can write and open |
| **Memories** | Polaroid-style photo gallery with lightbox |
| **Love Garden** | Interactive garden — click to plant flowers |
| **Little Surprises** | Open When envelopes, smile generator, wish jar, and heart catcher game |

## Personalisation

Click the ⚙️ Settings button (bottom-left) to customise:
- Site title & names
- Welcome message
- Special date (calculates days together)
- Blush pink / lavender theme toggle

All data (notes, memories, moments, wishes, garden) persists via **localStorage**.
